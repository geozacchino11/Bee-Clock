# CNC Wooden Bee Clock — Autodesk Fusion 360

A complete **CAD/CAM manufacturing project** featuring the 3D design, CNC toolpath programming, and machining simulation of a wooden **Bee Clock**, created in **Autodesk Fusion 360**.

## Overview
This project was built to practice end-to-end subtractive manufacturing workflows in Fusion 360—taking a custom 3D model from initial CAD design through stock setup, CAM toolpath generation, and material-removal simulation for CNC machining out of a wooden board.

## Repository Contents

* **`Bee_Clock.f3d`** — Complete Autodesk Fusion 360 archive file containing:
  * **Design Workspace:** 3D parametric solid bodies and geometry for the bee-themed clock face and clock movement recess.
  * **Manufacture Workspace (`CAM`):** Stock configuration, work coordinate system (WCS) setup, and CNC milling toolpaths (`Setup1` / `Setup2`).
  * **Simulation Data:** Verified stock-removal simulation model ensuring collision-free machining on wood stock.

## Manufacturing Workflow & Skills Demonstrated
* **Software:** Autodesk Fusion 360 (Design & Manufacture Workspaces)
* **CAD Modeling:** 3D decorative profile modeling and functional pocket/bore design for clock hardware.
* **CAM Programming:** Stock definition for wooden board material, tool selection, feeds & speeds configuration, and multi-operation toolpath generation.
* **Verification:** 3D toolpath simulation and post-processing preparation for CNC router execution.
